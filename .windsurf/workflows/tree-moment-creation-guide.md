# LoveBud 트리 & 순간 생성 가이드

## 개요

이 가이드는 LoveBud 테스트 환경에서 러브트리와 순간을 효과적으로 생성하는 방법을 설명합니다.

---

## 1. 사전 준비

### 1.1 테스트 계정 확인
- `test-accounts.json`에서 유효한 QA 계정 확인
- 계정이 Firebase Auth에 등록되어 있어야 함
- 로그인 실패 시 새 계정 생성 필요 (회원가입 flow 사용)

### 1.2 필수 확인 사항
- **Slot URL**: `https://test{N}.lovebud.pages.dev` (N = 5,6,7,8,9,10)
- **배포된 SHA 확인**: 반드시 expected SHA와 일치하는지 확인
- **로그인 상태**: My Trees 페이지 접근 가능 여부 확인

---

## 2. 트리 생성 단계

### 2.1 My Trees 페이지 접근
```
URL: {slot_url}/pages/my-trees.html
```

### 2.2 새 트리 버튼 클릭
- "새 트리" 또는 "add 새 트리" 버튼 클릭
- 다이얼로그 제목: "어떤 러브트리를 남길까요?"

### 2.3 트리 정보 입력
| 필드 | 값 예시 |
|------|---------|
| 트리 제목 | 아티스트명 (예: "아일릿", "Close Your Eyes") |
| 시작 목표 | "둘러보기에 소개될 트리로 키우기" (기본값) |

### 2.4 트리 생성 완료
- "이 트리로 시작하기" 버튼 클릭
- Editor 페이지로 자동 이동 확인
- 화면에 "순간을 이어가는 중" 표시 확인

---

## 3. 순간 추가 단계

### 3.1 순간 추가 시작
- "첫 순간 심기" 또는 "새 순간 이어가기" 버튼 클릭
- 다이얼로그: "첫 순간을 심어볼까요?"

### 3.2 순간 유형 선택
- **링크로 시작**: 유튜브 URL 입력 (권장)
- **텍스트로 시작**: 직접 메모 작성

### 3.3 유튜브 순간 입력
| 필드 | 설명 | 예시 |
|------|------|------|
| 링크 주소 | 유튜브 URL | `https://www.youtube.com/watch?v=9UoYXCR8ITE` |
| 순간 제목 | 기억에 남을 제목 | "아일릿 데뷔 Magnet 첫 무대" |
| 메모 한 줄 | 감상평/느낌 | "귀여운 소녀들의 에너지 넘치는 데뷔 무대" |

### 3.4 순간 저장
- "첫 순간 심기" 버튼 클릭
- 저장 완료 확인:
  - Editor에 썸네일 표시
  - "순간이 저장되었습니다" 또는 자동 저장 표시
  - "새 순간 이어가기" 버튼 활성화

## 4. 검증 체크리스트

- [ ] 저장 상태 "저장됨" 표시

## 5. 오류 대응

### 5.1 로그인 실패 (INVALID_LOGIN_CREDENTIALS)
1. 다른 QA 계정 시도 (user1~user9)
2. 새 계정 생성:
   - 회원가입 탭으로 전환
   - 닉네임/이메일/비밀번호 입력
   - "회원가입 완료" 클릭
3. `test-accounts.json`에 새 계정 정보 기록

### 5.2 유튜브 링크 인식 실패
- 전체 URL 입력 (예: `https://www.youtube.com/watch?v=...`)
- "시작 시간" 파라미터 제거 후 시도
- 다른 영상 URL로 테스트

### 5.3 저장 실패
- 필수 필드 누락 확인 (제목, 링크)
- 네트워크 연결 확인
- 페이지 새로고침 후 재시도

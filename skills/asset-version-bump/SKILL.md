# Asset Version Bump

## 이 스킬을 언제 쓰이나?

- **Deploy 시**: 버전 번호 갱신
- **JS/CSS 파일 변경 시**: HTML 참조 URL 갱신
- **캐시 무효화**: 새 버전에 old 캐시 적용 방지

## 입력으로 필요한 것

| 항목 | 필수 | 설명 |
|------|------|------|
| 현재 버전 | 선택 | 없으면 계산된 값 기준 |
| 변경 파일 | 필수 | *.js, *.css 파일 목록 |

## 출력 결과

- 새 버전 번호: `?v=YYYYMMDD-N`
- 갱신된 HTML 파일 목록

## 버전 번호 계산 규칙

```
Format: ?v=YYYYMMDD-N
- YYYYMMDD: 오늘 날짜 (변경 없음)
- N: 날짜별 최고번호의 누적 합
```

### 계산 원리

> **중요**: 아래 예시의 숫자는 설명을 위한 가상의 값입니다. 실제 작업 시에는 반드시 현재 HTML 파일에 있는 실제 버전값을 먼저 확인하고 적용하세요.

1. HTML에서 모든 `?v=` 패턴을 추출
2. 각 날짜(YYYYMMDD)별 **최고번호**를 찾음
3. 모든 날짜의 최고번호를 **합산**
4. 오늘 날짜 + 합산 결과를 N으로 설정

### 계산 예시

> **예시임**: 실제 값이 아닙니다. 반드시 현재 HTML을 먼저 확인하세요.

```
현재 HTML 버전들:
  ?v=20260415-14  → 20260415 최고 14
  ?v=20260416-16  → 20260416 최고 16
  ?v=20260417-30  → 20260417 최고 30 (직전)

날짜별 최고번호 합산: 14 + 16 + 30 = 60

오늘(2026-04-17) 다음 버전: ?v=20260417-61
```

### 현재 버전 확인

```bash
# 모든 ?v=YYYYMMDD-* 패턴 검색
grep -rh '\?v=' --include="*.html" pages/ | sort -u

# 또는 ripgrep
rg '\?v=\d{8}-\d+' -t html -o | sort -u
```

## 작업 흐름

### 1. 현재 버전 확인

```bash
# 전체 버전 확인
grep -rh '\?v=' --include="*.html" pages/ | sort -u | tail -10
```

### 2. 새 버전 번호 계산

> **중요**: 예시 값입니다. 실제 현재 HTML을 확인 후 적용하세요.

```bash
# 1단계: 날짜별 최고번호 찾기
# 출력 예: 20260415-14, 20260416-16, 20260417-30
rg '\?v=\d{8}-\d+' -t html -o | sort -u

# 2단계: 각 날짜의 최고번호 합산
# 예: 14 + 16 + 30 = 60

# 3단계: 오늘 버전 결정
# 오늘이 20260417이면 ?v=20260417-60 → 다음 ?v=20260417-61
```

### 3. 파일 변경 (관련 파일만 정확히)

> **중요**: 실제 현재 버전값으로 정확한 패턴을 지정하세요.

```bash
# ✅ 권장: sed로 정확한 패턴만 변경
# 예: 20260417-30 → 20260417-61 (합산 결과)
sed -i 's/?v=20260417-30/?v=20260417-61/g' index.html

# 또는 특정 파일만 변경
sed -i 's/?v=20260417-30/?v=20260417-61/g' index.html pages/detail.html pages/search.html

# ❌ 금지: broad 변경 (다른 날짜 버전까지 바뀜)
# sed -i 's/?v=20260417-30/?v=20260417-61/g' *.html
```

### 4. 검증

```bash
# 변경된 버전만 확인
rg '\?v=' -t html -o | sort -u | tail -5

# 전체 URL 패턴 확인
rg '\.js\?v=|.css\?v=' -t html
```

## 자주 쓰는 명령어 모음

```bash
# 현재 모든 버전 (최신 순)
grep -rh '\?v=' --include="*.html" pages/ | sort -u | tail -5

# 날짜별 최고번호 확인
grep -rh '\?v=2026041' --include="*.html" pages/

# 특정 날짜 최고값 찾기
grep -rh '\?v=20260417-' --include="*.html" pages/
```

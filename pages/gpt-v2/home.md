# LoveTree Home (Landing Page) Design Document (v2)

이 문서는 제공된 고해상도 디자인 시안을 바탕으로 LoveTree(러브트리) 홈 페이지의 시각적 요소, 레이아웃, 콘텐츠 및 인터랙션 모델을 정의합니다.

## 1. 디자인 철학 및 무드 (Visual Identity)
- **Concept**: "따뜻한 디지털 스크랩북", "감정의 정원"
- **Aesthetic**: Warm & Wide. 아날로그 소품(폴라로이드, 마스킹 테이프, 집게, 자필 메모)을 활용하여 정서적이고 친근한 느낌을 전달합니다.
- **Color Palette**: 
    - 베이스: 부드러운 크림/베이지 계열 (#F9F5F0 추정)
    - 포인트: 차분한 핑크/코랄 (#D68C8C), 따뜻한 골드/앰버
- **Typography**: 
    - 메인 헤드라인: 명조체 계열을 사용하여 서정적인 분위기 강조
    - 본문/UI: 가독성이 좋은 고딕(Sans-serif) 계열 (예: Pretendard, Inter)

## 2. 레이아웃 구조 (Layout Structure)

### 2.1 Header (Navigation)
- **좌측**: 서비스 로고 (심볼 + 러브트리 LoveTree)
- **우측**: 메뉴 (둘러보기, 내 트리, 로그인) + '시작하기' 강조 버튼 (둥근 모서리, 코랄 배경)

### 2.2 Hero Section (Identity & Collage)
- **메시지**: 
    - 타이틀: "좋아하는 순간을, 러브트리로 키워보세요"
    - 서브텍스트: 사랑한 장면, 노래, 기억, 감정을 모아 하나의 트리로 자라나게 하는 서비스의 핵심 가치 전달
- **CTA Buttons**:
    - [내 트리 시작하기] (강조형, 코랄/핑크)
    - [공개 트리 둘러보기] (라인형/고스트 버튼)
- **Visual Collage**: 
    - 폴라로이드 사진 (순간), 자필 메모(오늘의 한 줄), 음악 플레이어 위젯(감정), 아날로그 영수증/메모지(기억)가 자유롭게 배치된 형태.
    - 요소 사이를 잇는 덩굴과 빛나는 입자 효과로 '성장'과 '연결'의 은유 표현.

### 2.3 Key Features (Value Proposition)
세 개의 둥근 사각형 카드 형태로 서비스의 주요 기능을 소개합니다.
1. **대표 순간**: "좋아하는 장면과 감정을 가장 먼저 남겨요" (아이콘: 별)
2. **이어진 감정**: "순간과 순간이 감정의 흐름으로 연결돼요" (아이콘: 깨진 하트/연결된 형태)
3. **나만의 트리**: "좋아하는 기억을 하나의 러브트리로 키워가요" (아이콘: 나무)

### 2.4 Public Feed (마음이 닿은 트리들)
- **타이틀**: "마음이 닿은 트리들" (서브: 다른 팬들이 가꾼 따뜻한 트리를 만나보세요)
- **트리 카드 구성**:
    - 썸네일 (가로형 이미지)
    - 트리 제목 (예: "보랏빛 순간", "빛나던 무대")
    - 짧은 설명 및 태그/아이콘
    - 인터랙션 정보 (좋아요 수, 댓글 수)

## 3. 인터랙션 및 효과
- **Glimmer & Bloom**: 배경 및 히어로 섹션 이미지에 은은한 빛 번짐(Bloom) 효과와 파티클 효과 적용.
- **Glassmorphism**: UI 카드 배경에 미세한 투명도와 블러 효과를 주어 배경과 조화롭게 배치.
- **Smooth Transition**: 페이지 스크롤 및 카드 호버 시 부드러운 상승 효과나 그림자 변화 적용.

## 4. 콘텐츠 데이터 (Copy)
- **메인 카피**: 좋아하는 순간을, 러브트리로 키워보세요
- **설명 문구**: 사랑한 장면과 노래, 기억과 감정을 차곡차곡 모아 두면, 서로의 결이 이어져 하나의 트리로 자라납니다. 러브트리는 마음속 순간들을 오래 간직하고 천천히 돌볼 수 있는 감정의 정원입니다.

## 5. 디자인 시안 vs 현재 구현체 차이점 (Gap Analysis)

현재 구현된 페이지(`pages/gpt-v2/home`)와 원본 디자인 시안을 비교했을 때 다음과 같은 주요 차이가 발견됩니다.

| 구분 | 디자인 시안 (Target) | 현재 구현체 (Current) | 차이점 요약 |
| :--- | :--- | :--- | :--- |
| **전체 레이아웃** | 배경 전체를 활용한 와이드한 일체형 구성 | 좌(텍스트) / 우(콜라주)로 분리된 화이트 카드 레이아웃 | 개방감 부족 및 '정원' 느낌의 파격적 연출 미흡 |
| **배경 및 분위기** | 은은한 패브릭 질감, 블룸(Bloom) 효과, 파티클 | 단순 베이지 배경, 평면적인 카드 구조 | '따뜻한 감성'과 '풍부한 레이어' 부족 |
| **히어로 콜라주** | 배경 위에 떠 있는 유기적인 배치, 복잡한 덩굴 | 우측 카드 내부에 갇힌 정형화된 배치 | 아날로그 스크랩북 특유의 자유로운 감성 약화 |
| **디테일 소품** | 마스킹 테이프, 집게, 정교한 그림자 처리 | 단순한 선과 평면적인 카드 | 실물 소품이 주는 촉각적(Tactile) 경험 부재 |
| **헤더 디자인** | 미니멀하고 투명한 형태, 프리미엄한 느낌 | 일반적인 웹 내비게이션 바 형태 | 서비스 아이덴티티 반영 부족 |
| **음악 위젯** | LP판 디자인, 정교한 재생 컨트롤 UI | 단순한 이미지와 텍스트 조합 | 인터랙션 요소의 디테일 부족 |

## 6. 시안과의 간극을 줄이기 위한 제안 (Action Plan)

### 6.1 시각적 풍성함 강화 (Aesthetic Polish)
- **배경 텍스처 적용**: 단순 색상 대신 미세한 종이/패브릭 질감을 오버레이하여 아날로그 감성 부여.
- **조명 효과 (Bloom/Glow)**: 핵심 이미지와 입자(Particle)에 은은한 CSS `filter: blur()` 및 `box-shadow`를 사용하여 '빛나는 순간' 표현.
- **그림자 깊이 조정**: 요소들이 실제로 종이 위에 놓인 것처럼 보이도록 `drop-shadow`의 거리와 블러 값을 정교하게 조정.

### 6.2 레이아웃의 유연성 확보
- **카드 경계 허물기**: 텍스트와 콜라주를 감싼 인위적인 화이트 박스를 제거하거나 배경과 자연스럽게 블렌딩되도록 수정.
- **유기적 연결선**: 덩굴(Vine) 그래픽이 카드 경계에 끊기지 않고 화면 전체를 가로지르도록 SVG 애니메이션 또는 절대 위치 활용.

### 6.3 디테일 소품 추가
- **마스킹 테이프/집게**: 각 폴라로이드 요소 상단에 마스킹 테이프나 집게 그래픽을 추가하여 '스크랩'된 느낌 강화.
- **음악 플레이어 고도화**: 시안에 있는 원형 LP 디자인과 프로그레스 바를 실제 CSS/SVG로 구현.

### 6.4 타이포그래피 및 간격
- **자간 및 행간 최적화**: 시안의 여유롭고 서정적인 타이포그래피 느낌을 위해 메인 헤드라인의 `letter-spacing`과 `line-height`를 미세 조정.
- **폰트 웨이트**: "러브트리" 단어에 시안과 동일한 포인트 컬러와 폰트 가중치 적용.

# LoveTree Home (Landing Page) 구현 가이드 및 기술 명세 (v2)

이 문서는 제공된 고해상도 디자인 시안(Image 1)과 현재 구현체(Image 2) 간의 간극을 분석하고, 원본의 감성을 100% 복원하기 위한 구체적인 구현 기준을 정의합니다.

## 1. 현재 구현이 원본과 다른 핵심 이유 (Core Gaps)
1. **타이포그래피 위계 및 호흡**: 원본은 제목의 줄바꿈과 자간을 통해 서정적인 리듬감을 형성하나, 현재는 일반적인 웹 제목 수준의 정직한 배치를 가짐.
2. **헤더의 존재감**: 원본 헤더는 투명하고 요소 간 간격이 넓어 프리미엄한 느낌을 주나, 현재는 상단 바 형태의 경계가 뚜렷하여 범용 웹 사이트 느낌이 강함.
3. **히어로 섹션 좌우 밀도 비대칭**: 원본은 우측 콜라주 영역이 텍스트 영역보다 더 넓고(약 4:6) 요소들이 군집(Cluster)을 이루어 꽉 찬 느낌을 주나, 현재는 5:5 비율로 요소들이 분산되어 있음.
4. **오브제 간 유기적 관계**: 중앙 카드(오늘의 한 줄)를 중심으로 사진과 선들이 하나의 생태계처럼 얽혀있으나, 현재는 각 요소가 독립적으로 배치된 느낌임.
5. **사진의 톤앤매너(Color Grading)**: 원본 사진들은 배경의 크림/베이지 톤에 맞춰 따뜻한 필터가 적용되어 있으나, 현재는 고대비의 공연 사진이 배경에서 튀어 보임.
6. **디테일 소품의 부재**: 실물 질감의 마스킹 테이프, 금속 핀, 왁스 실, 말린 안개꽃 등 '촉각적 경험'을 주는 요소가 CSS 도형으로 대체되어 리얼리티가 낮음.
7. **하단 영역의 감성**: 하단 카드와 섹션이 기능 중심의 '대시보드 UI'처럼 처리되어 히어로 섹션의 감성적인 흐름이 끊김.

## 2. 필수 반영 요소 (Mandatory)
- [ ] **헤더 개편**: 배경 투명화, 내비게이션 자간 확대, 우측 유저 필의 미니멀화.
- [ ] **히어로 비율 조정**: 콜라주 영역을 60% 이상으로 확대하고 요소들을 중앙으로 밀집(Clustering).
- [ ] **타이포그래피 최적화**: "좋아하는 순간을," / "러브트리로 키워보세요"의 2행 구성 및 "러브트리"의 로즈 골드 톤(#D68C8C) 적용.
- [ ] **중앙 앵커 카드 강화**: 음악 플레이어가 포함된 노트를 가장 큰 위계로 설정.
- [ ] **사진 톤 보정**: 모든 사진 에셋에 Warm/Rose 필터 적용 (CSS `sepia` 및 `hue-rotate` 활용).

## 3. 선택 반영 요소 (Optional)
- [ ] **마이크로 애니메이션**: 나뭇잎이 흔들리거나 빛 입자가 마우스 커서를 따라오는 반응형 효과.
- [ ] **배경 커튼 효과**: 화면 양 끝에 흐릿한 패브릭 텍스처 오버레이.

## 4. 보류 요소 (Deferred)
- [ ] **실시간 음악 재생 로직**: 디자인 복원 우선 순위에 따라 실제 스트리밍 기능은 UI 구현 이후로 보류.

## 5. CSS로 해결할 것
- **텍스트 스타일링**: `font-family: "Nanum Myeongjo"`, `letter-spacing: -0.05em`, `line-height: 1.15`.
- **배경 조명**: `radial-gradient`와 `filter: blur()`를 조합한 Bloom 효과.
- **사진 필터**: `filter: brightness(0.9) sepia(0.2) saturate(1.1)`.
- **헤더/카드 투명도**: `backdrop-filter: blur(12px)`와 저농도 알파값(`rgba(255,255,255,0.2)`).

## 6. SVG로 해결할 것
- **유기적 덩굴(Vine)**: 기하학적 원형이 아닌, 불규칙한 곡률을 가진 덩굴 선 드로잉.
- **아이콘**: 별, 하트, 나무 등의 심볼을 시안과 동일한 굵기와 선 맛으로 재제작.

## 7. 에셋이 꼭 필요한 것 (External Assets)
- **리얼 소품 이미지**: 투명 배경의 마스킹 테이프(PNG), 말린 안개꽃(PNG), 구리 핀/왁스 실(PNG).
- **배경 텍스처**: 패브릭 커튼 질감 이미지.

## 8. 구현 우선순위
1. **1순위**: 히어로 섹션 비율 및 타이포그래피 위계 수정 (전체 인상 결정).
2. **2순위**: 중앙 콜라주 군집화 및 레이어링 고도화.
3. **3순위**: 헤더 및 하단 카드 영역 감성 보정 (기능 UI -> 감성 UI).
4. **4순위**: 에셋 추가를 통한 리얼리티 극대화 (테이프, 꽃, 왁스 실).

## 9. 수정 대상 파일 목록
- `pages/gpt-v2/home.html`: 전체 구조 및 인라인 스타일 수정.
- `css/gpt-v2/common.css`: 헤더, 버튼, 카드 공통 위젯 스타일 고도화.

## 10. 최종 검수 기준

- [ ] 우측 콜라주가 파편화되지 않고 하나의 예술적 군집으로 보이는가?
- [ ] 폰트와 컬러톤이 배경의 크림색과 충돌 없이 녹아드는가?
- [ ] 헤더와 하단 섹션이 히어로 섹션의 감성을 방해하지 않는가?

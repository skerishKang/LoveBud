# LoveBud Chat-First Tree Workspace — Concept Image Assets

이 폴더는 LoveBud **chat-first tree workspace** 콘셉트 이미지 시안을 보관합니다.

- 현재 런타임 반영 대상이 아닌 **UX 실험/기획 참고 자료**입니다.
- Issue #1321과 연결되어 있습니다.

## 이미지 목록

| 파일 | 설명 |
|------|------|
| `chat-first-desktop-start.png` | 데스크톱 첫 진입 화면. 중앙 대화창 중심. |
| `chat-first-desktop-workspace.png` | 데스크톱 대화 시작 후 화면. 왼쪽 80% 트리/순간 작업공간, 오른쪽 20% 대화 패널. |
| `chat-first-mobile-start.png` | 모바일 첫 진입 화면. 대화 입력 중심. |
| `chat-first-mobile-workspace.png` | 모바일 대화 시작 후 화면. 대화 중심 + 트리/순간 탭 또는 바텀시트 접근. |

## 참고

- 이미지 안의 문구는 **최종 제품 copy가 아니라 참고용 예시**입니다.
- 실제 구현 시 단순 일기앱처럼 보이지 않도록 **관계/순간/트리/브랜치/패턴 탐색** 중심으로 재설계해야 합니다.
- 유료 기능 또는 프리미엄 UX로 분리 가능성은 후속 실험 후 판단합니다.

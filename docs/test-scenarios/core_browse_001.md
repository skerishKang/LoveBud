# CORE-BROWSE-001

이 문서는 공개 트리 둘러보기에서 상세 보기로 이어지는 감상 흐름을 검증하는 현재 대표 시나리오입니다.

목적은 비로그인 또는 일반 탐색 사용자가 search 화면에서 공개 트리를 보고, 관심 있는 트리를 선택하고, detail로 이동해 감정 흐름을 감상하는 경험이 자연스러운지 확인하는 것입니다.

---

## 1. 왜 중요한가

Browse는 제품의 공개 쇼케이스 역할을 합니다.
이 흐름이 좋으면 신규 사용자는 로그인 전에 제품 가치를 이해할 수 있고, 공개 트리의 매력도 확인할 수 있습니다.

핵심은 다음입니다.
- search 화면에서 무엇을 볼 수 있는지 이해되는가
- 공개 트리 카드 정보가 충분한가
- detail 진입이 자연스러운가
- 뒤로가기나 재탐색이 끊기지 않는가

---

## 2. 범위

대상 페이지:
- search
- detail

핵심 질문:
- 공개 트리 탐색이 직관적인가
- 카드와 preview 정보가 충분한가
- detail에서 트리 맥락이 이해되는가
- browse에서 detail로 갔다가 다시 돌아오는 흐름이 안정적인가

---

## 3. 사전 준비

- 공개 트리가 최소 1개 이상 존재해야 함
- 결과 폴더 권장 형식: `docs/test-scenarios/results/core-browse-001-{group}-YYYY-MM-DD-HHMM/`

---

## 4. 단계

### STEP 1. search 첫 인상
행동:
- search 화면에 진입한다.

확인 포인트:
- 공개 트리를 둘러보는 페이지라는 점이 이해되는가
- 필터와 카드 구조가 직관적인가
- 미리보기 영역의 역할이 이해되는가

기록 항목:
- 첫 인상
- 목적 이해도
- 혼란 포인트

### STEP 2. 카드/필터 탐색
행동:
- 카드 목록을 훑고, 필요 시 필터를 바꾼다.

확인 포인트:
- 카드 정보가 선택 판단에 충분한가
- 필터 반응이 자연스러운가
- 감정 태그, 대표 썸네일, 메타 정보가 과하거나 부족하지 않은가

기록 항목:
- 카드 정보 충분성
- 필터 이해도
- 탐색 피로도

### STEP 3. preview 확인
행동:
- 한 트리를 선택하거나 hover하여 preview를 본다.

확인 포인트:
- preview가 선택 전에 도움이 되는가
- 대표 순간과 감정 태그가 유용한가
- preview와 카드 정보가 일관적인가

기록 항목:
- preview 유용성
- 정보 일관성

### STEP 4. detail 진입
행동:
- 공개 트리 하나를 선택해 detail로 이동한다.

확인 포인트:
- 이동이 빠르고 자연스러운가
- detail에서 보고 있는 순간과 트리 맥락이 이해되는가
- 단독 순간, 연결된 조각, 트리 문맥이 어색하지 않은가

기록 항목:
- 이동 결과
- detail 이해도
- 가독성

### STEP 5. browse로 복귀
행동:
- 뒤로가기를 하거나 browse 맥락으로 돌아간다.

확인 포인트:
- 이전 탐색 상태가 크게 깨지지 않는가
- 사용자가 다시 목록 탐색을 이어가기 쉬운가

기록 항목:
- 복귀 안정성
- 탐색 연속성

---

## 5. 에지 체크

- 검색 결과가 적을 때도 화면이 어색하지 않은가
- 대표 썸네일 또는 preview가 비어 있어도 깨지지 않는가
- detail 직접 진입과 browse 경유 진입의 차이가 과도하지 않은가

---

## 6. 최종 판정

통과:
- search에서 detail까지의 탐색 흐름이 자연스럽고, 감상 맥락이 유지된다.

조건부 통과:
- 탐색은 가능하지만 카드/preview/detail 연결이 다소 어색하다.

실패:
- 공개 탐색의 목적이 잘 드러나지 않거나, detail 진입/복귀 흐름이 크게 불안정하다.

   - 제안: JavaScript 디버깅, API 연결 확인

2. **새 트리 만들기 버튼 불명확**
   - 현상: 로그인 후 내 러브트리 페이지에서 새 트리 만들기 버튼이 보이지 않음

   - 제안: 메인 대시보드에 "+ 새 트리 만들기" CTA 버튼 명확히 배치

### 🟡 우선순위 중간 (사용성)

3. **트리 편집/삭제 기능 부재**
   - 현상: 트리 목록에서 수정/삭제 옵션이 없음

   - 제안: 트리 항목에 "⋮" (점 3개) 메뉴 버튼 추가 → 수정/삭제/이름 변경

   - 영향: 트리가 많아질 때 관리 어려움
   - 제안: 사이드바 또는 메인 메뉴에 "내 트리 목록" 추가

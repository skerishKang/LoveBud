## 현재 상태 (2026-09-30 기준)

**공개 Git credential bundle channel = RETIRED ✅**

공개 저장소에 credential bundle을 배포하던 채널은 폐기되었습니다.
이전에 `docs/ops/qa-credential-bundle/` 아래에 커밋되었던 암호화 번들은 더 이상
추적되지 않으며, Git history에서 복원하거나 다시 커밋해서는 안 됩니다.
(과거 기록 보존용 tombstone: `docs/ops/qa-credential-bundle/README.md`)

현재 working 방법: **승인된 비공개 credential 저장소** (password manager / custodian 관리 secret store)
임시 handoff (Issue #351)는 superseded되었습니다.

해당 계정들의 rotation/retirement은 **별도 권한으로 승인된 작업**이며 아직 수행되지 않았습니다.

```text
STATUS=RETIRED_PUBLIC_GIT_CREDENTIAL_CHANNEL
NO_CREDENTIAL_MATERIAL_TRACKED_HERE
APPROVED_CURRENT_SOURCE=승인된 비공개 password manager / custodian 관리 secret store
HISTORICAL_GIT_COPY=NONAUTHORITATIVE
ROTATION_STATUS=ROTATION_REQUIRED
HISTORICAL_BLOB_EXISTS_POSSIBLY=YES
CREDENTIAL_ROTATION_REQUIRED=YES
```

DO_NOT=
- Git history / 이전 commit / tag / fork에서 credential 복원 금지
- historical archive 압축 해제 금지 (검증 목적 포함)
- 어떤 credential archive도 저장소에 다시 커밋 금지

## 현재 설정 절차

### 1. 승인된 비공개 저장소 사용 (권장)
- 승인된 password manager / custodian 관리 secret store에서 필요한 항목을 조회

- credential source = `approved non-public store` 로 보고

### 2. `docs/ops/qa-credential-bundle/` 또는 Git history를 사용하지 않음
- 폐기된 채널입니다
- Git history / 이전 commit / fork에서 credential을 복원하지 않음
- historical archive를 압축 해제하여 확인하지 않음
- 어떤 credential archive도 저장소에 다시 커밋하지 않음

### 3. `.local/test-accounts.json`이 이미 존재하는 경우
- 이는 **문서 기반 복원 성공이 아닙니다**
- `credential source: pre-existing local file` 로 보고

## 운영 원칙

- 저장소에는 **실제 비밀번호를 남기지 않음**
- 저장소에는 **공개-safe 메타데이터만** 남김 (라벨, credential key, persona/role, 환경, 상태, 민감도 등급, custodian 라벨)
- 저장소에는 **어떤 credential archive도 커밋하지 않음**
- 문서에는 **경로/사용법/주의사항**만 기록
- 실제 값은 **승인된 비공개 저장소**에서만 관리하며, 로컬 `.local/test-accounts.json`은 런타임 편의용
- credential rotation은 **별도 권한으로 승인된 custodian/provider 작업**이며 문서 변경과 함께 수행하지 않음
- `ops/temp-qa-credential-handoff` branch는 임시 경로이므로 cleanup 후 사라질 수 있음

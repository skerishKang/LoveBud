## 파일 naming 규칙
실제 운영 파일명 형식:
- `YYYY-MM-DD-NN-짧은제목.md` (권장)
- 예: `2026-04-17-01-runtime-stabilization.md`
- `NN`은 해당 날짜의 세션 회차 (01부터 시작)

## 핵심 주제

LoveBud Netlify 배포본(`https://lovebud.netlify.app/`)의 MVP 핵심 루프가 정상 동작하는지 확인하는 스모크 QA 검증 지침을 제공하는 문서. 실제 구현이 아니라 QA 작업을 위한 가이드로, 검증 범위, 확인 항목, 보고 형식을 정의함.

---

## 확정 판단

- **검증 대상**: Netlify 배포본 기준, 실제 사용자 흐름을 통한 동작 확인.
- **범위**: `index → my-trees → editor → detail` 핵심 루프와 `search → detail` 감상 흐름.
- **우선순위**: 구현 코드 수정 금지, "되는 것/깨지는 것" 판정만. 치명적 이슈만 우선 보고.
- **보고 형식**: 최종 판정(통과/수정 후 재검증/실패), 치명적 이슈, 주요 확인 결과(페이지별), 경미한 이슈, 최종 권고.

## 남은 blocker

1. **구체적인 검증 기준 불명**: " 깨지지 않는지"의 판정 기준이 주관적일 수 있음. 각 항목별 통과/실패 기준 추가 필요 가능성.
2. **환경 의존성**: Netlify 배포본의 실제 DB 연결 상태, 인증 환경에 따라 검증 결과가 달라질 수 있음.
3. **치명적 이슈 판단 기준**: "치명도 높은 이슈"의 구체적 정의가 없어 보고자와 검토자 간 기준 차이 가능성.

---

## 다음 액션

1. 실제 QA 검증 수행: `https://lovebud.netlify.app/`에서 명시된 8단계 루트 및 세부 항목 확인.
2. 검증 결과를 지정된 형식(최종 판정 → 치명적 이슈 → 주요 확인 결과 → 경미한 이슈 → 최종 권고)으로 기록.
3. 발견된 이슈가 있을 경우, severity(치명/경미)와 재현 절차를 명확히 기재.

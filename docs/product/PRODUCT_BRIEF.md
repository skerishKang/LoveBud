# LoveBud Product Brief

> 기준: 2026-04-17 | 컴2 (작업 사본)

## 한 줄 설명

**팬의 입덕 첫 순간을 기록하고, 감정 경로를 시각화하는 디지털 스크랩북**

---

## 핵심 사용자

| 사용자 | 현재 상태 |
|--------|----------|
| 입덕 직후의 팬 | ✅ My Trees에서 첫 트리 생성 가능 |
| 경로 기록을 원하는 팬 | ✅ Editor에서 memory 추가 가능 |
| 커뮤니티를 탐색하고 싶은 팬 | ✅ Search에서 public tree 탐색 가능 |

---

## 핵심 경험

1. **첫 기억 기록**: 유튜브 영상의 특정 시점 + 감정 메모로 "입덕의 순간"을 기록
2. **경로 시각화**: 기록된 순간들을 나무 형태로 연결하여 감정 흐름을 확인
3. **비공개 우선**: 기본 비공개, 선택적 공유

---

## LoveBud가 지향하는 감정 경험

- **처음❤️**: 입덕의 그 강렬한 첫 순간을 가장 소중하게
- **연결🌿**: 순간들을 파편화하지 않고 감정 경로로 연결
- **감정💭**: 단순한 저장보다 "왜 이 시점이 좋았는지"에 가치
- **따뜻함🌸**: 차갑고 딱딱한 인터페이스 대신 따뜻하고 자연스러운 경험

---

## LoveBud가 하지 않을 것 (MVP 범위 밖)

| 제외 항목 | 이유 |
|----------|------|
| 일반 북마크 도구 | 감정 기록이 핵심 |
| 관리자 대시보드 | 사용자 중심 |
| 범용 커뮤니티 피드 | 비공개 우선, 공유는 선택 |
| 대규모 소셜 | 소셜보다 감정 연결이 먼저 |
| 자동 추천 알고리즘 | 수동으로 기록하는 것이 핵심 |

---

## 현재 핵심 루프 상태

| 페이지 | 상태 | 핵심 기능 |
|--------|------|-----------|
| my-trees | ✅ 동작 | 비공개 트리 관리 |
| editor | ✅ 동작 | memory 추가/시각화 |
| search | ✅ 동작 | 공개 트리 탐색 |
| detail | ✅ 동작 | 트리/메모리 상세 보기 |
| login | ✅ 동작 | Firebase 인증 |

# Lovetree User Flow

> Lovetree는 처음 사랑에 빠진 순간부터 팬이 되어가는 경로를 영상과 메모로 연결해 남기는 **팬 감정 러브트리**입니다.

---

## Core User Journey

### Phase 1: 입덕의 첫 순간 (First Moment)

```
[유튜브 영상 감상 중]
       │
       ▼
"이 시점이 너무 좋아!" ← 핵심 감정 발생
       │
       ▼
[러브트리 앱 열기]
       │
       ▼
"순간 기록하기" 클릭
       │
       ├──► URL 입력 / 클립보드에서 자동 추출
       ├──► 시점(timestamp) 설정
       ├──► 짧은 제목 입력
       ├──► 감정 태그 선택 (예: "#감동 #입덕 #처음")
       └──► 메모 작성 (왜 이 순간이 특별한지)
```

### Phase 2: 러브트리 성장 (Tree Growth)

```
첫 순간이 트리의 "뿌리"가 됨
       │
       ▼
더 많은 영상 시점을 기록할 때마다
나뭇가지처럼 연결됨
       │
       ▼
"연결하기" 모드에서
새로운 순간을 기존 노드에 연결
       │
       ├── 부모 노드 선택
       ├── 새 순간 기록
       └── 감정 흐름의 연속성 유지
```

### Phase 3: 감상하기 (Reflection)

```
내 러브트리 보기
       │
       ▼
타임라인 모드: 시간순으로 보기
       │
트리 모드: 나뭇가지 구조로 보기
       │
감상 모드: 특정 순간만 집중해서 보기
```

### Phase 4: 공유하기 (Sharing)

```
완성된 러브트리 → "공유하기" 클릭
       │
       ▼
비공개: 나만 보기 (기본값)
       │
공개: 커뮤니티에서 감상 가능
       │
       ▼
다른 팬이 내 경로를 보며
"나도 저렇게 입덕하고 싶다" 느끼기
```

## Mobile vs Desktop Flow

### Mobile: 빠른 기록 & 감상

```
[영상을 보던 중]
       │
       ▼
러브트리 앱 스와이프
       │
       ▼
"빠르게 추가" 버튼
       │
       ├── URL 붙여넣기
       ├── 시점 자동/수동 설정
       ├── 감정 태그 선택
       └── 저장 → 완료 (3초以内)
```

### Desktop: 연결 구조 & 편집

```
[트리의 전체 구조를 보며]
       │
       ▼
"연결하기" 모드 활성화
       │
       ▼
노드 A를 선택 → "여기에 연결"
       │
       ▼
새 노드 B 생성
       │
       ├── 제목, 메모, 태그 입력
       └── 연결 완료
       │
       ▼
트리 구조가 자연스럽게 성장
```

```
       │

       │
       ▼
"감동이야" → 공감 버튼

"コメント" → 감정 나�리기
       │
       ▼

```

## Emotional Flow Principles

Lovetree의 감정 흐름은 다음과 같은 특성이 있습니다:

1. **시간的不是 선형**: 입덕은 순간마다 다양한 시점에서 발생
2. **연결은 감정 기반**: 기술적 의존성보다 "이 순간이 저 순간과 연결된다"는 감정적 연관성
3. **트리 구조는 자연스러움**: 인공적인 분류가 아닌, 나뭇가지처럼 자연스럽게 성장

---

## Decision Checklist

기능을 추가할 때 이 흐름에 맞는지 확인:

1. 이 기능이 **"첫 순간 기록"**에 도움이 되는가?
2. 이 기능이 **"연결"**의 감정을 강화하는가?
3. 이 기능이 **"감상"**의 경험을 풍부하게 하는가?
4. 이 기능이 **"차갑지 않은"** 경험인가?

## State Transitions

| 현재 상태 |Trigger |다음 상태 |
|---------|--------|---------|
| 빈 트리 |첫 기록 추가|성장 중|
| 성장 중|연결 생성|더 큰 트리|
| 성장 중|감상 선택|감상 모드|
| 비공개|공유 설정|공개|
| 공개|설정 변경|비공개|

# 제품 문서 인덱스

이 폴더에는 LoveBud 제품의 정의, 범위, 사용자 흐름, 정체성 등 **제품 관련 문서**가 저장됩니다.

## 용도
- 제품의 방향성과 범위 명시
- MVP 정의 및 사용자 여정
- 브랜드 정체성 및 디자인 원칙
- 팬페이지 기반 감성 UX / 페이지 경험 기준 정리
- 전역 UI 카피 운영 기준 정리
- 공개/비공개/둘러보기 소개 UX 정책 정리

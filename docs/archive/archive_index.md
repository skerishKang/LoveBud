# 보관 문서 인덱스

이 폴더에는 **레거시/과거 문서** 및 보관된 자료가 저장됩니다.

## 구조
```
archive/
├── analysis/   # 분석 문서 (과거)
├── guides/     # 가이드 문서 (보관)
└── plans/      # 계획서/기획서 (이력)
```

## 용도
- 현재 활성 개발과 직접 관련 없는 문서
- 과거 결정/연구 자료 보관
- 참고용 레거시 문서

## 하위 폴더

| 폴더 | 내용 |
|------|------|
| `analysis/` | 과거 분석 보고서 |
| `guides/` | 오래된 가이드 문서 |
| `plans/` | 기존 계획서 및 초안 |
| `identity/` | 제품 정체성 인터뷰 자료 및 보관 문서 |

## 포함된 문서 (예시)
- `minimax2.7_draft.txt` — Minimax 2.7 초안 (루트에서 이동 예정)

# 📋 테스트 절차 및 시나리오 정합성 감사 보고서

**날짜:** 2026-04-20
**작성자:** Antigravity (AI 에이전트)
**대상:** LoveBud 테스트 체계 및 에이전트 수행 원칙

## 1. 개요
하츠투하츠(Hearts2Hearts) 데이터로 진행한 `CORE-NEWUSER-001` 시나리오 수행 과정에서 발견된 에이전트의 판단 착오와 시나리오 문서의 결함을 분석하고 개선안을 기술함.

## 2. 발견된 주요 문제점

### (1) [치명] 테스트 격리(Isolation) 실패 (에이전트 과실)
- **현상**: '신규 사용자'를 가정하는 테스트임에도 불구하고, 에이전트가 이전 작업의 로그인 세션(기존 트리 7개 존재)이 남은 상태에서 테스트를 진행함.
- **영향**: 신규 사용자가 마주하는 '빈 화면(Empty State) UI'와 '진입 장벽'을 전혀 검증하지 못했으며, 단순히 기존 유저의 트리 추가 기능만 확인하는 반쪽짜리 테스트가 됨.
- **원인**: 테스트 시작 전 세션 초기화(Logout & Cache Clear)를 수행해야 한다는 절차적 의식 부족.

### (2) [매우 높음] 시나리오 용어 정합성 불일치 (문서 결함)
- **현상**: 시나리오 문서에서 메인 CTA(Call To Action) 버튼을 실제 텍스트인 **"나의 첫 러브트리 만들기"** 대신 **"시작하기"**라는 범용적 표현으로 기술함.
- **영향**: 실제 인터페이스와 지침서가 일치하지 않아 인간 테스터나 AI 에이전트가 버튼을 찾는 과정에서 혼선을 줄 수 있으며, 정밀한 UX 검증을 방해함.

### (3) [보통] 테스트 데이터 포맷 불일치 (데이터 결함)
- **현상**: `hearts2hearts-data.json`에 포함된 Mock 유튜브 ID(`H2H_Debut_MV`)가 제품의 실제 URL 검증 로직(11자리 ID 필수)에 의해 거절됨.
- **영향**: 테스트 수행 중 '링크가 유효하지 않다'는 에러를 마주하게 되어 흐름이 끊기고, 에이전트가 임의로 실제 유튜브 ID를 찾아 대체해야 하는 비효율 발생.

## 3. 개선 조치 현황

### [조치 완료] 시나리오 문서 보강 (`core_newuser_001.md`)
1. **STEP 0 (Clean Start)**: 테스트 시작 전 로그아웃 및 브라우저 저장소 초기화 과정을 필수 의무 사항으로 명문화함.
2. **명칭 동기화**: 문서 내 모든 "시작하기" 표현을 실제 UI 문구인 "**나의 첫 러브트리 만들기**"로 수정 완료.
3. **실패 판정 기준**: 신규 유저 테스트 시 기존 데이터가 남아있는 경우를 명백한 '실패'로 규정함.

## 4. 제언 및 향후 계획

1. **AGENTS.md 업데이트**: 모든 에이전트가 세션 초기화 원칙을 준수하도록 전역 헌장(Charter) 수준에 명시.
2. **테스트 데이터 전수 점검**: `docs/test-scenarios/data/*.json` 내의 모든 URL이 실제 검증 로직을 통과할 수 있는 유효한 형식을 갖추도록 수정.
3. **실제 신규 유저 재테스트**: 위 조치사항을 바탕으로 하츠투하츠 데이터를 사용해 진짜 'Empty State'부터 시작하는 재테스트 수행 권장.

# my-trees (내 러브트리)

## 페이지 목적
사용자가 자신의 러브트리 목록을 보고, 새 트리를 시작하거나 선택한 트리를 바로 이어보는 관리 화면.

## 사용자 목표
1. 내 트리 목록 확인
2. 새 트리 생성
3. 선택한 트리 이어보기
4. 트리 이름, 공개 범위, 삭제 등 기본 관리

---

## 현재 구현 상태 (main 기준)

### 주요 UI 섹션
- **페이지 헤더**: 내 러브트리 제목 + 안내 문구 + 새 러브트리 버튼
- **관리 요약 바**: 전체 트리 수, 공개/비공개 수, 순간 수, 정렬, 선택 트리 빠른 액션
- **트리 카드 그리드**: 대표 비주얼, 순간 수, 공개 범위, 정렬/선택/열기/더보기
- **새 트리 시작 모달**: 제목 + 공개 범위 설정 후 바로 생성

### 현재 파일 구조
- `pages/my-trees.html`
- `js/my-trees.js`
- `js/my-trees/*` 모듈들 (`my-trees-ui`, `my-trees-actions`, `my-trees-data`, `my-trees-state` 등)
- `js/i18n/i18n-my-trees.js`
- `js/my-trees/my-trees-i18n-refresh.js`

| 문제 | 설명 |
|------|------|
| 초기 하드코드와 i18n 차이 | 첫 렌더 기본 문구와 i18n 문구가 일부 달랐음 → 이번 정리에서 주요 항목 동기화 |

## 상태별 화면

### 1. 로딩 중
- 러브트리 목록 로딩 텍스트 노출
- 로딩 상태 컨테이너 표시

### 2. 트리 있음
- 카드 그리드 표시
- 상단 관리 바에서 선택한 트리 빠른 액션 가능
- 더보기 메뉴에서 공개 전환 / 이름 변경 / 삭제 접근 가능

### 3. 빈 상태
- 아직 러브트리가 없다는 안내
- 새 러브트리 만들기 CTA 제공

### 4. 새 트리 시작
- 모달에서 트리 제목 입력
- 공개/비공개 범위 선택
- 생성 후 이어서 편집 흐름으로 진입

### 5. 에러 상태
- 불러오기 실패 안내 + 다시 시도 버튼

## 필요한 데이터/API

| 데이터 | 소스 | 비고 |
|--------|------|------|
| trees list | `apiClient.getTrees()` | 내 트리 목록 로드 |
| create tree | `apiClient.createTree(payload)` | 제목/공개 범위 기반 생성 |
| update tree | `apiClient.updateTree(treeId, payload)` | 이름/공개 범위 변경 |
| delete tree | `apiClient.deleteTree(treeId)` | 트리 삭제 |

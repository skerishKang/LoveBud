# editor (러브트리 편집)

## 페이지 목적
선택한 러브트리 안에서 순간의 흐름을 보고, 현재 순간을 중심으로 새 순간을 이어 심거나 기존 순간의 제목·메모·태그를 다듬는 핵심 편집 화면.

## 사용자 목표
1. 트리의 현재 흐름을 한눈에 보기
2. 첫 순간 또는 다음 순간 추가
3. 선택한 순간의 정보 확인 및 수정
4. 트리 제목과 공개 범위 빠르게 정리

> 용어 기준:
> - UI 용어: **순간**, **트리**, **감정 메모**
> - 내부 구현 용어: **memory**, **node**
> - editor는 순간을 노드로 보여주지만, 사용자에게는 "기억"보다 **순간** 중심 문구를 우선 사용합니다.

## 현재 구현 상태 (main 기준)

### 주요 UI 섹션
- **좌측 패널**: 트리 제목, 공개 범위, 순간 수, 흐름 요약, `트리 한눈에 보기`, `새 순간 이어가기`
- **가운데 캔버스**: 트리 흐름 시각화, 빈 트리 안내, 순간 추가 affordance
- **우측 현재 순간 허브**: 현재 순간 정보, 메모/태그/날짜, 수정/삭제, 상세 이동
- **순간 추가 모달**: 링크 입력 모드 + 텍스트 입력 모드 지원

### 현재 파일 구조
- `pages/editor.html`
- `js/editor.js`
- `js/editor/*` 모듈들 (`editor-canvas`, `editor-detail-ui`, `editor-memory-form`, `editor-data-loader` 등)
- `js/i18n/i18n-editor.js`
- `js/editor/editor-i18n-refresh.js`

## 현재 문제/리스크

| 문제 | 설명 |
|------|------|
| fallback 문자열 의존 | 일부 editor 문구가 i18n key 없이 fallback에 기대고 있었음 → 이번 정리에서 주요 항목 보완 |
| 용어 혼재 | 과거의 `기억`, `영상 추가` 계열 문구가 문서/일부 fallback에 남아 있을 수 있음 |
| 링크 지원 설명 | 실제로는 링크 없이도 저장 가능하지만, 일부 오래된 설명은 YouTube 중심으로 읽힐 수 있었음 |
| 문서 노후화 | 예전 editor 구조/버튼 설명이 문서에 남아 있었음 |

## 상태별 화면

### 1. 빈 트리
- 가운데 캔버스에 첫 순간 안내 노출
- 좌측/우측에서도 첫 순간 시작 CTA 제공
- 첫 순간을 심으면 현재 순간 허브가 활성화됨

### 2. 트리 편집 중
- 캔버스에서 전체 흐름 확인
- 좌측에서 트리 제목/공개 범위 조정
- 우측에서 현재 순간 메모와 세부 정보 확인

### 3. 순간 추가 모달
- **링크 모드**: YouTube 장면 링크 + 제목 + 감정 메모
- **텍스트 모드**: 링크 없이 제목과 감정 메모만으로 저장
- 링크가 있으면 대표 장면/썸네일 미리보기 보조 제공

### 4. 순간 수정/삭제
- 우측 패널에서 제목, 메모, 태그 수정
- 삭제 후 선택 상태와 캔버스가 함께 갱신됨

## 필요한 데이터/API

| 데이터 | 소스 | 비고 |
|--------|------|------|
| tree data | `apiClient.getTree(treeId)` | 트리 메타 포함 |
| memories | `apiClient.getMemoriesByTree(treeId)` | editor 캔버스/패널 기준 데이터 |
| create memory | `apiClient.createMemory(memoryData)` | 링크/텍스트 모드 공통 |
| update memory | `apiClient.updateMemory(memoryId, payload)` | 제목/메모/태그 수정 |
| delete memory | `apiClient.deleteMemory(memoryId)` | 순간 삭제 |

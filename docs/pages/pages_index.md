# LoveBud 페이지 문서

이 폴더에는 LoveBud MVP 핵심 페이지별 문서가 저장됩니다.

## 페이지 목록

| 페이지 | 파일 | 설명 |
|--------|------|------|
| **my-trees** | [my-trees.md](my-trees.md) | 내 비공개 트리 목록, 생성, 선택 |
| **editor** | [editor.md](editor.md) | 트리 시각화, 메모리 추가/편집 |
| **search** | [search.md](search.md) | 공개 트리 탐색, 필터, 검색 |
| **detail** | [detail.md](detail.md) | 메모리 상세 보기, 연결된 기억 확인 |

## 문서 구조

각 페이지 문서에는 다음이 포함됩니다:
- 페이지 목적
- 사용자 목표
- 현재 구현 상태
- 현재 잘 되는 것
- 현재 문제/리스크
- 상태별 화면 (로딩/성공/빈/에러)
- 필요한 데이터/API
- 다음 개선 포인트

## 사용법

다음 세션에서 페이지를 빠르게 파악하려면:
1. `docs/pages/`에서 해당 페이지 문서 찾기
2. "현재 문제/리스크"와 "다음 개선 포인트" 확인
3. 필요하면 상위 문서 `docs/product/`와 비교

06 · Technical Risk

인프라 최적화 방향

현재 4중 레이어 구조 → 2단 구조로 단순화 필요

⚠️ 현재 리스크
  • Cloudflare → Modal → Vercel → Netlify 4중 레이어
  • 운영 복잡도 높음 → 장애 추적 어려움
  • Vanilla JS + HTML → 팀 확장 시 확장성 제한
  • 번들러 부재 → 코드 스플리팅 불가
✅ 권장 방향
  • Cloudflare Pages + Modal 2단 구조 단순화
  • Netlify 레거시 경로 단계적 제거
  • 유저 1,000명 돌파 시 React 마이그레이션 계획
  • 모니터링 도구 (Sentry / Cloudflare Analytics) 도입

💡 핵심 원칙: 기술 완성도보다 실제 팬덤 유저 검증이 우선. 인프라 단순화는 MVP 검증 이후 진행해도 무방.
